# Клиенты и заказы — приложение на C++ / Qt 6

Небольшое настольное приложение для учёта клиентов и заказов. Интерфейс на русском языке, данные сохраняются локально в SQLite.

## Возможности
- Вкладка «Клиенты и заказы»: список заказов, которые ещё находятся в работе.
- Добавление клиента вместе с первым заказом.
- Добавление новых заказов существующему клиенту.
- Перенос заказа во вкладку «Выполненные заказы».
- Статус выполненного заказа: «Ожидает выдачи» или «Выдан».
- Удаление выбранного заказа.
- Автоматическое сохранение данных в локальной базе SQLite.

## Сборка
Нужны Qt 6 (модули Widgets и Sql), CMake 3.21+ и компилятор C++17.

```bash
cmake -S . -B build
cmake --build build --config Release
```

Запустите полученный исполняемый файл `ClientOrders` (Windows: `ClientOrders.exe`).

Для Windows можно собрать проект через Qt Creator: откройте `CMakeLists.txt`, выберите комплект Qt 6 Desktop и соберите конфигурацию Release.

## Где хранятся данные
База `clients.sqlite` автоматически создаётся в системной папке данных приложения (AppDataLocation). Удаление приложения само по себе не удаляет эту базу.

## Примечание
Это исходный проект, а не готовый установщик. Для сборки исполняемого файла требуется установленный Qt 6 и компилятор под целевую операционную систему.


## Сборка Windows 10 через GitHub Actions
В репозитории уже добавлен workflow `.github/workflows/build-windows.yml`.
1. Загрузите содержимое проекта в новый GitHub-репозиторий.
2. Откройте вкладку **Actions**.
3. Выберите **Build Windows 10 app** → **Run workflow**.
4. После завершения откройте результат запуска и скачайте артефакт `ClientOrders-Windows10-x64`.
5. Распакуйте ZIP и запустите `ClientOrders.exe`.

Сборка выполняется на Windows Server 2022 с MSVC и Qt 6; полученная программа предназначена для Windows 10 x64.
